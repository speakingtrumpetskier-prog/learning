# Super Mario Level

A fun, playable Super Mario-style platformer game built with HTML5 Canvas and JavaScript!

## Features

- Classic platformer gameplay with jumping and running
- Multiple platforms at different heights
- Collectible coins scattered throughout the level
- Question mark blocks that give you coins when hit from below
- Enemy Goombas that patrol platforms
- Goal flag to complete the level
- Score tracking system
- Lives system
- Responsive controls

## How to Play

1. Open `index.html` in your web browser
2. Use the arrow keys to move Mario:
   - **Left Arrow**: Move left
   - **Right Arrow**: Move right
   - **Up Arrow** or **Space**: Jump
3. Collect coins to increase your score
4. Hit question mark blocks from below to get bonus coins
5. Jump on enemies (Goombas) to defeat them
6. Reach the flag at the end to complete the level
7. Avoid falling off platforms or getting hit by enemies

## Scoring

- Coins: 50 points each
- Question mark blocks: 100 points each
- Defeating enemies: 200 points each

## Game Elements

- **Green platforms**: Safe ground to walk on
- **Red platforms**: Floating platforms
- **Yellow blocks with "?"**: Coin blocks (hit from below)
- **Gray blocks**: Brick blocks
- **Yellow circles**: Collectible coins
- **Brown enemies**: Goombas (jump on them to defeat)
- **Green flag**: Level goal

## Tips

- Time your jumps carefully to land on higher platforms
- Jump on enemies from above to defeat them safely
- Collect all coins for a higher score
- Don't let enemies touch you from the side
- You have 3 lives - use them wisely!

Enjoy playing!
