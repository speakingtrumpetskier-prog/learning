CLEAR VISION CARS — updating the website
=========================================

BEFORE / AFTER PHOTOS  (the hero slider)
----------------------------------------
The slider shows two images:
  assets/headlight-before.jpg   (left side)
  assets/headlight-after.jpg    (right side)

To use real job photos, replace BOTH files with your own pair,
keeping the same file names. Best results: same headlight, same
angle and distance, landscape orientation, both photos the same
width and height. Refresh the page, done.

(The current before image is generated from the stock after photo
by tools-bake-oxidation.ps1 in this folder - you can delete that
script once real photos are in.)
